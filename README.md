# Premier Chess (EPL-themed PWA)
1. Create a GitHub repo, upload these files to the root.
2. Settings > Pages > Deploy from branch `main` / root.
3. Open `https://<you>.github.io/<repo>/` on your phone, open it once online, then Install / Add to Home Screen.
4. Online play is enabled only in the installed app. Host shares the code, friend joins. Coin toss picks White.
Engine: Stockfish.js (CDN, cached for offline). P2P: WebRTC via PeerJS (public signalling server).
